# Learnt how to Create a Virtual Environment Using uv (Windows)

### 1. Create a Virtual Environment

```bash
uv venv .venv
```

This creates a virtual environment named `.venv` in the current project directory.

### 2. Activate the Virtual Environment

```powershell
.venv\Scripts\Activate
```

### 3. Deactivate the Virtual Environment

```bash
deactivate
```
